Douyin Auto-Vietsub Pro 🎬🇻🇳Công cụ hỗ trợ tải video từ Douyin (TikTok Trung Quốc), Kuaishou và tự động tạo phụ đề Tiếng Việt (Vietsub) bằng công nghệ AI.Lưu ý: Giao diện này hiện tại là phiên bản Front-end (Web App) chứa luồng UI/UX hoàn chỉnh. Các chức năng gọi API tải video và dịch thuật AI đang được mô phỏng (Mocking). Cần kết nối với Backend thực tế để công cụ hoạt động 100%.✨ Tính năng nổi bậtTải Video Lẻ: Nhập URL video từ Douyin/TikTok để phân tích, lấy link tải không logo (No Watermark).Tải & Vietsub Cả Kênh (Batch Download): Quét toàn bộ video từ một Profile/Kênh, hỗ trợ chọn nhiều video để tải và xử lý hàng loạt.Tích hợp Trình phát Video: Xem trước video với phụ đề mềm (Softsub - định dạng VTT/SRT) ngay trên trình duyệt trước khi tải xuống.Auto-Vietsub: Giao diện sẵn sàng tích hợp với các công cụ Speech-to-Text (như OpenAI Whisper) và Dịch thuật (Google Translate, Gemini).Thiết kế hiện đại: Giao diện tối màu (Dark mode), Glassmorphism mượt mà, Responsive trên cả điện thoại và máy tính.🛠️ Công nghệ sử dụngDự án được xây dựng theo kiến trúc Single-File đơn giản nhất để dễ dàng triển khai:HTML5 / CSS3React 18 (chạy trực tiếp qua CDN, không cần Node.js/Webpack).Tailwind CSS (qua CDN) cho giao diện UI.FontAwesome 6 cho icon.🚀 Hướng dẫn cài đặt & Chạy dự ánVì dự án chạy trực tiếp không cần build, bạn chỉ cần thực hiện 2 bước:Clone repository này về máy:git clone https://github.com/your-username/douyin-vietsub-pro.git
Mở file index.html trực tiếp bằng trình duyệt bất kỳ (Chrome, Edge, Safari...).Trải nghiệm ngay trên web (Không cần tải):(Gắn link GitHub Pages của bạn vào đây sau khi bật)🔗 Hướng dẫn cho Developer (Kết nối Backend)Để công cụ này hoạt động với dữ liệu thật, bạn cần tìm trong file index.html các comment // MÔ PHỎNG GỌI API BACKEND và thay thế logic setTimeout bằng hàm fetch() gọi đến server của bạn.Cấu trúc quy trình thực tế:Frontend (App này): Gửi URL Douyin lên Backend.Backend (Node.js/Python):Gọi API (VD: RapidAPI Douyin Watermark-free) để lấy link MP4 gốc.Tải MP4 về server, dùng FFmpeg tách file Audio (.mp3 / .wav).Gửi file Audio qua API AI (Whisper) để lấy Text Tiếng Trung.Dịch Text Tiếng Trung sang Tiếng Việt.Tạo file .vtt hoặc .srt và trả về URL cho Frontend.Frontend (App này): Gắn URL MP4 và URL .vtt vào thẻ <video> để hiển thị.⚠️ Tuyên bố miễn trừ trách nhiệmCông cụ này được tạo ra với mục đích học tập và nghiên cứu.
